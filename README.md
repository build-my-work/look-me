# Look Me

Look Me 是一个 macOS 护眼陪伴应用：刘看山以透明、置顶的小宠物形态常驻桌面，在本机检测完整眨眼，并在持续近距离工作后提示 20 秒远眺。

它是个人健康习惯工具，不用于诊断或治疗干眼症。摄像头画面只在内存中交给 MediaPipe Face Landmarker 处理，不上传、不保存；无法可靠看到人脸时会暂停眨眼提醒，恢复检测后重新计时。应用只在本机保留最近 30 天的分钟级眨眼、有效观察、坐姿与离座汇总，不保存精确事件时间或坐姿校准坐标。

## MVP 能力

- 用户主动授权后，在本机检测“睁眼 → 闭眼 → 睁眼”的完整眨眼
- 展示近 1 分钟频率估算、当前连续检测段平均和本次累计次数
- 展示按日期切换的全天每分钟频率曲线；未观察或观察不足的分钟显示为空白
- 双眼 blendshape + 眼部关键点 EAR 的时序确认，过滤单眼眨和长时间闭眼
- 每次确认完整眨眼后，刘看山会同步眨一次眼；未检测到人脸时不会伪造这一反馈
- 低置信度、遮挡或摄像头不可用时暂停眨眼提醒，并在状态中明确说明
- 可单独开关的远眺提醒：开启后每 20 分钟提示远眺 20 秒，可跳过本次提醒
- 透明、置顶、点击穿透的 760 × 300 Electron 常驻窗口与托盘入口
- 按住刘看山即可拖动原生窗口；拖到屏幕边缘时会保留完整拖拽区域，按钮仍可点击，其余透明区域继续穿透
- 可从菜单栏把刘看山切换为小、标准或大；只缩放 pet 和它的眨眼/拖拽区域，统计卡片与按钮保持原尺寸
- “显示眨眼次数”从属于“始终显示看山”；面板用于查看当前状态和打开统计，隐藏面板不会停止本地统计
- 刘看山右键菜单和菜单栏提供持久化的“监测与提醒”总开关；看山设置提供独立的眨眼、远眺提醒开关和可选的每日开始/结束时间，默认时段为 09:00–21:00
- 一路摄像头和一次 Face Landmarker 推理同时服务眨眼与坐姿监测，两个信号状态机和历史存储彼此独立
- 自动学习稳定坐姿下的脸部高度；确认脸向上离开画面后统计起身次数、连续坐姿、今日坐姿与离座时长
- 突然丢脸、侧向离开和摄像头暂停均不算起身；“离座”只表示向上离画后的时间，不宣称精确站立

## 调整刘看山大小

点击 macOS 菜单栏中的 Look Me 图标，选择“看山大小”，再选择“小”“标准”或“大”。小档约为标准档的 41%；选择会保存在本机，下次启动自动恢复。

## 显示或隐藏眨眼次数

点击 macOS 菜单栏中的 Look Me 图标，先启用“始终显示看山”，再勾选或取消“显示眨眼次数”。面板用于查看检测状态并打开统计，统计中的“查看全天曲线”继续进入历史图表。关闭“始终显示看山”会同时关闭并保存“显示眨眼次数”，再次启用看山后可按需重新开启；隐藏面板不会停止最近 30 天的分钟级统计。

## 设置监测与提醒

刘看山右键菜单和 macOS 菜单栏中的 Look Me 菜单都提供高频的“监测与提醒”总开关；关闭后会释放摄像头，并停止眨眼提醒、自动远眺和注意力动画。进入“看山设置…”可分别配置眨眼提醒、远眺提醒和监测时段：只关闭“眨眼提醒”时仍继续本地统计与自动远眺，只关闭“远眺提醒”时仍继续眨眼监测。未可靠检测到人脸时不使用计时兜底，眨眼提醒会暂停；恢复检测后从零计算 25 秒未眨眼时间。重新开启任一能力后不会补发关闭期间的提醒。锁屏、睡眠或处于监测时段外时采用相同的暂停规则。

```bash
cd app
npm install
npm run dev:desktop
```

仅预览浏览器界面：

```bash
cd app
npm run dev
```

```bash
cd app
npm run typecheck
npm test
npm run build
npm run test:sites
npm run desktop:dir
```

macOS arm64 开发包会生成在 `app/release/mac-arm64/Look Me.app`。该本地开发包未签名，第一次打开时需由用户确认系统安全与摄像头权限。

## 检测实现

- 模型：Google MediaPipe Face Landmarker（本地 `face_landmarker.task`）
- 信号：同一份人脸帧分发给眨眼状态机（`eyeBlinkLeft`、`eyeBlinkRight`、双眼 EAR）和坐姿状态机（双眼中线的画面纵坐标）
- 采集：优先请求 1280 × 720 / 24 FPS；推理约 20 FPS，页面不可见时暂停
- 远距离：较弱的双眼闭合系数必须同时得到强 EAR 下降确认，不会单独放宽为眨眼
- 原则：模型只输出感知信号；提醒、暂停和冷却由独立状态机决定
- 历史：每个本地自然日按分钟稀疏聚合，至少有效观察 15 秒才展示该分钟频率，自动保留 30 天
