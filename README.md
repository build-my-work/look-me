# Look Me 👀

**Look Me（看看我）** —— 刘看山住进你的桌面：本地视觉护眼陪伴，提醒你眨眼、远眺、起身。

盯屏入神的时候，人会不知不觉地不眨眼，泪膜得不到刷新，眼睛干涩酸胀；久坐和长时间紧盯，也在悄悄累积负担。Look Me 让刘看山以透明置顶的小宠物形态常驻桌面，替你留意这些小事——他不是监控你，只是在你需要的时候，眨眨眼提醒你一下。

🏠 官网：[lookme.anme.cc](https://lookme.anme.cc/)

> 🔒 所有检测都在本机完成：摄像头画面只在内存中处理，**不上传、不保存**。

## ✨ 特性

- 🐹 **刘看山住进桌面**：透明、置顶、点击穿透的小窗口，按住看山即可拖动到任意位置；小 / 标准 / 大三档大小可切换，空闲时他还会打哈欠、鼓掌、坐下、转圈
- 👁 **完整眨眼检测**：双眼 blendshape 与眼部关键点 EAR 双信号时序确认，过滤单眼眨和长时间闭眼；每确认一次，看山会同步眨眼回应你
- 💧 **眨眼陪伴**：实时估算近 1 分钟眨眼频率；长时间没有完整眨眼时，看山会温和地提醒，而不是弹出吓人的弹窗
- 🌄 **远眺提醒**：累计 20 分钟有效看屏后，提示远眺 20 秒，可随时跳过
- 🪑 **久坐提醒与坐姿统计**：自动学习你的稳定坐姿基线，起身次数、连续坐姿、今日久坐时长一目了然；久坐提醒默认 30 分钟，1–600 分钟任意可调
- 😴 **哈欠检测**：看山会实时镜像你的嘴部开合；明显张嘴保持约 0.9 秒，就记为一次哈欠
- 📊 **30 天行为时间轴**：按日期回看自己的每一天——「事件」视图在泳道上逐秒回放每一类事件，「次数统计」视图自动聚合眨眼、哈欠、站起、坐下的趋势
- 🔔 **提醒各自独立**：眨眼、远眺、久坐提醒可分别开关；默认监测时段 09:00–21:00，可自定义；一键暂停监测即释放摄像头
- 🔒 **本地优先**：检测、统计、历史数据全部留在本机，没有任何账号与云端

## 🎮 快速上手

- **托盘菜单**（macOS 菜单栏 / Windows 任务栏 / Linux 状态栏）：看山大小、始终显示看山、显示眨眼次数、监测与提醒总开关、退出
- **右键看山**：打开与托盘相同的设置菜单；按住左键拖动即可移动窗口
- **看山设置**：分别配置眨眼、远眺、久坐提醒与监测时段，选择看山的空闲小动作
- **统计面板**：查看近 1 分钟眨眼频率、今日有效看屏、坐姿统计；点击「查看行为时间轴」进入按日期回看的大视图

未可靠检测到人脸时（低置信度、遮挡、摄像头不可用），眨眼与坐姿提醒会暂停并明确告知原因，恢复检测后重新计时——不会用计时器兜底伪造提醒。隐藏看山或关闭统计面板不会停止本地记录。

## 🛠️ 技术栈

- 框架：Electron 43 + React 19 + TypeScript 7
- 构建：Vite 6 + electron-builder 26
- 视觉：MediaPipe Face Landmarker（本地推理）、Recharts、Phosphor Icons
- 存储：IndexedDB（30 天事件级 Timeline）
- 测试：Vitest 4

## ⚙️ 工作原理

- 模型：Google MediaPipe Face Landmarker（本地 `face_landmarker.task`），约 20 FPS 推理，页面不可见时暂停
- 一帧三用：同一份人脸帧分发给三个独立状态机——眨眼（`eyeBlinkLeft` / `eyeBlinkRight` + 双眼 EAR）、嘴部（`jawOpen`）、坐姿（眼部中线纵坐标）
- 远距离双信号：较弱的双眼闭合系数必须同时得到强 EAR 下降确认，不会单独放宽为眨眼
- 事件存储：Timeline 只保留六类事实事件（眨眼、哈欠、看屏与坐姿区间的开始/结束），按精确时间写入 IndexedDB，自动清理 30 天前的数据；提醒的触发与响应属于运行时状态，不落盘
- 起身判定：坐姿区间以配对的开始/结束事件记录，结束原因区分「完整站起」与「跟丢」——只有完整站起轨迹计入起身，突然丢脸、侧向离开不算

## 🔒 隐私说明

- ✅ 摄像头画面只在内存中交给本机 MediaPipe 推理，处理完即丢弃
- ✅ 只在本机保留最近 30 天的六类事件：眨眼、哈欠、看屏与坐姿区间的开始/结束
- ❌ 不上传任何数据，没有账号，没有云端
- ❌ 不保存原始画面、张嘴过程或坐姿校准坐标
- ❌ 不提供健康评分，Look Me 是个人健康习惯工具，不用于诊断或治疗干眼症

## 🐛 常见问题

**Q：macOS 打开时提示「无法验证的开发者」？**
A：安装包当前未签名。在系统设置 → 隐私与安全性中点「仍要打开」，或执行 `xattr -cr "/Applications/Look Me.app"`。

**Q：检测不到人脸时会怎样？**
A：低置信度、遮挡或摄像头不可用时，看山会暂停眨眼与坐姿提醒并说明原因，恢复检测后重新计时；这段时间不会被计入有效看屏。

**Q：隐藏看山之后，统计还在继续吗？**
A：在。隐藏面板只是隐藏，事件记录持续进行；只有关闭「监测与提醒」总开关、锁屏睡眠或超出监测时段时才会暂停采集并释放摄像头。

**Q：这是干眼症治疗工具吗？**
A：不是。Look Me 帮你养成眨眼、远眺、起身的护眼习惯，不能替代任何医疗诊断或治疗。
