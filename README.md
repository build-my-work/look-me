# Look Me

Look Me 是一个支持 macOS、Windows 和 Linux 的护眼陪伴应用：刘看山以透明、置顶的小宠物形态常驻桌面，在本机检测完整眨眼，并在累计有效看屏 20 分钟后提示 20 秒远眺。

它是个人健康习惯工具，不用于诊断或治疗干眼症。摄像头画面只在内存中交给 MediaPipe Face Landmarker 处理，不上传、不保存；无法可靠看到人脸时会暂停眨眼提醒，恢复检测后重新计时。应用只在本机保留最近 30 天的事件级 Timeline，其中只有六类事件：眨眼、哈欠、看屏区间的开始/结束、坐姿区间的开始/结束；不保存原始画面、张嘴过程或坐姿校准坐标。

## MVP 能力

- 用户主动授权后，在本机检测“睁眼 → 闭眼 → 睁眼”的完整眨眼
- 展示近 1 分钟眨眼频率估算、今日有效看屏、连续坐姿、今日久坐时长和今日起身次数
- 按日期切换的大视图行为时间轴，打开时扩展桌面窗口：「事件」视图把六类事件按精确时间放在独立泳道上，以固定 5 分钟窗口平移浏览；「次数统计」视图一次聚焦一个指标（眨眼、哈欠、站起、坐下），并随缩放自动选择从 1 分钟到 24 小时的聚合粒度，无采集覆盖的时段留空而不是计 0
- 双眼 blendshape + 眼部关键点 EAR 的时序确认，过滤单眼眨和长时间闭眼
- 刘看山会实时镜像你的嘴部开合；明显张嘴保持约 0.9 秒被确认为一次哈欠并记入时间轴
- 每次确认完整眨眼后，刘看山会同步眨一次眼；未检测到人脸时不会伪造这一反馈
- 低置信度、遮挡或摄像头不可用时暂停眨眼提醒，并在状态中明确说明
- 可单独开关的远眺提醒：开启后每累计有效看屏 20 分钟提示远眺 20 秒，可跳过本次提醒
- 透明、置顶、点击穿透的 760 × 300 Electron 常驻窗口与托盘入口
- 按住刘看山即可拖动原生窗口；拖到屏幕边缘时会保留完整拖拽区域，按钮仍可点击，其余透明区域继续穿透
- 可从菜单栏把刘看山切换为小、标准或大；只缩放 pet 和它的眨眼/拖拽区域，统计卡片与按钮保持原尺寸
- “显示眨眼次数”从属于“始终显示看山”；面板用于查看当前状态和打开统计，隐藏面板不会停止本地统计
- 刘看山右键菜单和菜单栏提供持久化的“监测与提醒”总开关；看山设置提供独立的眨眼、远眺、久坐提醒开关和可选的每日开始/结束时间，默认时段为 09:00–21:00
- 一路摄像头和一次 Face Landmarker 推理同时服务眨眼、哈欠与坐姿监测，各信号状态机保持独立并统一写入 Timeline
- 自动学习稳定坐姿下的脸部高度；确认脸向上离开画面后统计起身次数、连续坐姿、今日久坐时长与离座时长，坐姿区间以配对的开始/结束事件记录，因跟丢而结束的区间不计为起身
- 突然丢脸、侧向离开和摄像头暂停均不算起身；“离座”只表示向上离画后的时间，不宣称精确站立
- 久坐提醒默认开启且默认为 30 分钟，可在设置中输入 1–600 的任意整数分钟；关闭提醒不会停止坐姿统计

## 调整刘看山大小

点击系统托盘中的 Look Me 图标（macOS 上位于菜单栏），选择“看山大小”，再选择“小”“标准”或“大”。小档约为标准档的 41%；选择会保存在本机，下次启动自动恢复。

## 显示或隐藏眨眼次数

点击系统托盘中的 Look Me 图标（macOS 上位于菜单栏），先启用“始终显示看山”，再勾选或取消“显示眨眼次数”。面板用于查看检测状态并打开统计，统计中的“查看行为时间轴”继续进入事件与次数统计双视图。关闭“始终显示看山”会同时关闭并保存“显示眨眼次数”，再次启用看山后可按需重新开启；隐藏面板不会停止最近 30 天的事件记录。

## 设置监测与提醒

刘看山右键菜单和系统托盘中的 Look Me 菜单都提供高频的“监测与提醒”总开关；关闭后会释放摄像头，并停止眨眼提醒、自动远眺、久坐提醒和注意力动画。进入“看山设置”可分别配置眨眼提醒、远眺提醒、久坐提醒时间和监测时段：久坐提醒默认 30 分钟，可输入 1–600 的任意整数分钟；只关闭某项提醒不会停止其他提醒或本地统计。未可靠检测到人脸时不使用计时兜底，眨眼和连续坐姿提醒会暂停；恢复检测后重新计时。重新开启任一能力后不会补发关闭期间的提醒。锁屏、睡眠或处于监测时段外时采用相同的暂停规则。

```bash
cd app
npm install
npm run dev:desktop
```

```bash
cd app
npm run dev
```

## 验证与打包

```bash
cd app
npm run typecheck
npm test
npm run build
npm run test:sites
npm run desktop:dir
npm run desktop:package
```

`desktop:dir` 生成当前系统的免安装开发目录；`desktop:package` 生成当前系统的安装包。也可以按平台明确执行：

```bash
npm run desktop:mac
npm run desktop:win
npm run desktop:linux
```

安装包输出到 `app/release/`：

| 平台 | 安装包 |
| --- | --- |
| macOS | Intel 或 Apple Silicon 的 `.dmg` |
| Windows | x64 `.exe` 安装程序 |
| Linux | x64 `.AppImage` 和 `.deb` |

GitHub Actions 支持手动构建，也会在推送与 `package.json` 版本一致的 `v*` 标签时自动创建 GitHub Release。例如当前版本可执行：

```bash
git tag v0.1.0
git push gh v0.1.0
```

当前安装包默认未签名。macOS Gatekeeper 和 Windows SmartScreen 可能要求用户额外确认；面向普通用户无警告分发时，需要配置 Apple Developer ID、公证以及 Windows 代码签名证书。

## 检测实现

- 模型：Google MediaPipe Face Landmarker（本地 `face_landmarker.task`）
- 信号：同一份人脸帧分发给眨眼状态机（`eyeBlinkLeft`、`eyeBlinkRight`、双眼 EAR）、嘴部状态机（`jawOpen`）和坐姿状态机（双眼中线的画面纵坐标）
- 采集：优先请求 1280 × 720 / 24 FPS；推理约 20 FPS，页面不可见时暂停
- 远距离：较弱的双眼闭合系数必须同时得到强 EAR 下降确认，不会单独放宽为眨眼
- 原则：模型只输出感知信号；提醒、暂停和冷却由独立状态机决定
- 历史：Timeline 只保留六类事实事件，按精确时间写入本机 IndexedDB（`look-me:timeline:v2`），自动清理 30 天前的数据并删除旧版库；提醒的触发、展示与响应属于运行时状态，不落盘
- 坐姿：`seated.ended` 带 `stand_up` 或 `tracking_lost` 原因，只有完整站起轨迹才计为起身，随后同会话内新的 `seated.started` 才计为坐下；次数统计视图按可见范围动态选择聚合粒度
